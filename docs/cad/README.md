# CAD Models

3D CAD models of the EyefulTower robot capture rig.

## Files

| File | Description |
| --- | --- |
| `EyefulRobot.STEP` | STEP file with detailed 3D models of all cameras and sensors on the robot |
| `EyefulRobot.zip` | SolidWorks source files (`.SLDPRT` and `.SLDASM`) for the robot assembly |
| `Eyefulv2-elementary_geometry.STEP` | Simplified 3D model of the robot |

## File Formats

- **`.STEP`** — Standard for the Exchange of Product Data. An open, vendor-neutral 3D model format that can be opened in most CAD software (SolidWorks, Fusion 360, FreeCAD, etc.).
- **`.SLDPRT` / `.SLDASM`** — SolidWorks Part and Assembly files. These are the native editable source files and require [SolidWorks](https://www.solidworks.com/) to open.
